# Authors

## Creator & Maintainer

**Dan Young**
- Primary author and creator of the ClickHouse Migration Tool
- Architect of the configuration system and migration framework
- Developer of the original Frost weather monitoring system implementation

## Project History

This tool was originally developed by Dan Young for Frost's weather monitoring and agricultural technology system. The original implementation managed complex multi-database environments with ClickHouse and SQL Server, handling real-time IoT data, computer vision processing, and storm event tracking.

In 2025, Dan generalized the tool to make it available as an open-source solution for any team needing sophisticated ClickHouse migration management.
